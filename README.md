# Exercícios de TypeScript

Repositório dedicado à prática dos fundamentos de TypeScript, com exercícios sobre tipagem, funções, objetos, arrays, enums, interfaces, tratamento de dados e tipos avançados.

## Como executar

É necessário ter o [Node.js](https://nodejs.org/) e o TypeScript instalados.

Compile um exercício:

```bash
tsc --strict ex01.ts
```

Execute o JavaScript gerado:

```bash
node ex01.js
```

## Estrutura

- `ex01.ts` a `ex10.ts`: arquivos com os exercícios resolvidos.
- Arquivos `.js`: código JavaScript gerado pela compilação, quando mantidos no repositório.

## Objetivo

Praticar os principais recursos da linguagem TypeScript e desenvolver familiaridade com tipagem estática e validação de tipos.
